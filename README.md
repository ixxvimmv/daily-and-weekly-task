📅 Pink Task Tracker
A lightweight, mobile-friendly task management web app with a built-in calendar and live clock. Tasks are stored locally in the browser, ensuring they persist across sessions without requiring a database.

✨ Features
✅ Add and manage daily tasks for each day of the week
📝 Mark tasks as Done or Remove them
💾 Persistent storage using localStorage
📅 Integrated calendar with real-time clock
🌸 Minimal, pink-themed user interface
📱 Responsive design optimized for desktop and mobile
🚀 Usage

Open index.html in any modern web browser.
Select a day and add tasks.
Mark tasks as Done (toggle to undo) or Remove them.
View the live clock and calendar in the bottom-right corner.

🛠️ Technologies

CSS3
JavaScript (Vanilla)

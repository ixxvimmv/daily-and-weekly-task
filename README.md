📅 Pink Task Tracker
A simple, mobile-friendly daily task tracker with a built-in calendar and clock. Tasks are saved in your browser so they stay even after closing or refreshing the page.

✨ Features
✅ Add daily tasks for specific days of the week
📝 Mark tasks as Done or Remove them
💾 Saves tasks automatically using localStorage
📅 Includes a small calendar with the current time
🌸 Fully pink-themed design for a soft aesthetic
📱 Responsive design — works on phones and desktops

🚀 How to Use
Open the index.html file in your browser.
Select a day and add your tasks.
Use the Done button to mark finished tasks (toggle back to undo).
Use the Remove button to delete tasks permanently.
Check the calendar and live clock at the bottom right.

CSS3
JavaScript (Vanilla)
